# Discovery Question Bank

Pick only the questions that fill real gaps — skip anything already answered
by the conversation, the open Paper file, or the codebase. Ask via the
`questionnaire` tool, one tab per topic, 3–4 options per question, always
allowing "Type something".

## Intent

- "What should this design accomplish?"
  Options: solve a specific user problem / explore directions for an idea /
  redesign something that exists / validate a flow before building it.
- "What does success look like for the user on this surface?"
  Phrase options as task outcomes, not features ("finish in under a minute",
  "never wonder what to do next").

## Audience

- "Who is the primary user?"
  Options by role and expertise (e.g. first-time user / returning casual
  user / daily power user / admin).
- "What context do they use it in?"
  Options: focused desktop session / quick check on mobile / shared or
  kiosk screen / under time pressure.

## Journey

- "Where does the user come from when they arrive?"
  Options: deep link or notification / navigating from another screen /
  first-run onboarding / this is the app's home.
- "Which tasks must the flow support?" Offer the likely 3–4 tasks as
  options; the user can add more.
- "What is the successful end state, and where do they go next?"

## Scope & platform

- "How much should I design?"
  Options: single key screen / core flow (3–5 screens) / flow plus empty,
  loading, and error states.
- "What platform and size?"
  Options: mobile (375px) / desktop (1440px) / both.
- "New surface, or extending an existing design?" If extending, ask which
  artboard, page, or file to match.

## Brand & visual direction

- "Is there a design system or brand to match?"
  Options: match tokens in the open Paper file / match the codebase theme /
  fresh direction, surprise me.
- "What should it feel like?" Offer mood words: calm and focused / warm and
  human / bold and energetic / precise and technical.
- "Any products whose UX you admire — or want to avoid resembling?"

## Content

- "Do you have real copy and data, or should I write realistic
  placeholders?"

## Calibration shortcut

When the request is already specific, collapse all of the above into one
confirmation question: "Here's what I understood — intent, audience, scope,
direction. Anything to correct before I map the journey?"
